# Formula Navigator — актуальная инструкция (V16)

> Полные руководства — в двух PDF: **«руководство для коллег»** (что это, функции, установка) и **«гид владельца»** (как обновлять GitHub, выпускать версии, откатываться). Ниже — коротко про V16, V15.2, V15.1 и V15, затем V14 и история прошлых версий.

## Новое в V16

- **Trace и плавающее окно: диапазон — одна строка.** Раньше у `=INDEX(Data!D2:D500, MATCH(A1, Data!C2:C500, 0))` было 51 строка: первые 25 попавшихся ячеек из D, 25 из C и A1. Теперь три: `Data!D2:D500 · 499 cells`, `A1`, `Data!C2:C500 · 499 cells`.
  - Строка диапазона свёрнута; **→** показывает его заполненные ячейки — первые 25 и `… N more`.
  - **Enter** (или ↓ при Follow On) на строке диапазона или на `… N more` выделяет в Excel весь диапазон.
  - Для целых столбцов (`D:D`) — число заполненных ячеек (до «10,000+»); для имён — `Rates (Data!D2:D500)`; таблицы и 3-D диапазоны — тоже одной строкой.
  - Внизу окна: формула, где подсвечен этот диапазон, и «N filled cells». У ячеек внутри диапазона — та же формула с подсвеченным диапазоном.
  - Ссылки на одну ячейку (включая `(empty)`) — по-прежнему отдельные строки. Dependents не менялись.
- **«Найдено поиском» — первой строкой.** Для формулы, которую ты трассируешь, — зелёная строка `→ D15 · found by INDEX` (также VLOOKUP, HLOOKUP, XLOOKUP, OFFSET, INDIRECT): ячейка, которую поиск реально вернул. ↓ на неё переводит Excel туда, → раскрывает её прецеденты. Особенно полезно для INDIRECT и OFFSET — раньше Trace их источник не видел вообще.
  - **Защита:** строка появляется, только если вычислитель надстройки получил ровно то же значение формулы, что показывает Excel. Не совпало — строки нет (лучше промолчать, чем показать не ту ячейку).
  - Только для самой формулы (не на глубоких уровнях) и только в Precedents. Поиски в несработавшей ветке IF не показываются.
- **Explore: имена (named ranges) кликабельны.** Раньше строка имени (`Rate`, `Amounts`) ничего не делала. Теперь клик / Enter / Follow ведут туда, где имя реально находится: имя на ячейку — к ячейке (и ▸ раскрывает её формулу, если она там есть), имя на диапазон — выделяет диапазон. Так же ссылки на таблицы (`T[Amt]`).
- **Explore: имя больше не «сплющивается».** В V15 серый значок с определением имени съедал место и имя сжималось до «R» или исчезало. Теперь имя всегда видно, обрезается значок.
- **Explore: дерево каждой новой ячейки начинается заново.** Раньше раскрыто/свёрнуто переносилось с прошлой формулы по номеру строки — функция могла прийти свёрнутой, а ссылка раскрытой.
- **Проверки:** 324 автотеста + 161 проверка в браузере (Trace, окно, имена — на имитации Excel).

## Как обновить GitHub до V16

Залить из `formula-explorer/dist` **taskpane.js** и **dialog.js** (Add file → Upload files → Commit changes).

- Подожди ~10 минут.
- Проверка: открой `alimzhansagymbekov.github.io/formula-navigator/taskpane.js`, Ctrl+F5, Ctrl+F → `Formula Navigator V16`. После перезапуска Excel то же — первая строка в ⚙ → Diagnostics.
- Manifest не менялся — коллегам ничего делать не нужно, только перезапустить Excel.
- Если V15.x ещё не заливал — заливай сразу V16, она включает всё.

## Новое в V15.2

- **Explore больше не «теряет» исследуемую ячейку после переходов.** Раньше, особенно при переходе на другой лист или когда Excel занят, после Enter / клика / шага с Follow иногда пропадала кнопка «← Back», а дерево переключалось на ячейку, куда ты перешёл. Причина: Excel присылал событие «выделение изменилось» позже, чем надстройка его ждала (0,15 с), и она принимала его за твой клик. Теперь событие, которое сообщает ровно ту ячейку, куда надстройка сама перешла (в течение 3 с), — это эхо перехода, исследуемая ячейка не меняется. Твой настоящий клик в другую ячейку по-прежнему делает её исследуемой.
- **Follow On: Backspace снова возвращает к изначальной ячейке.** Раньше при прогулке стрелками та же ошибка «перекидывала» исследуемую ячейку на одну из пройденных, и Backspace возвращал уже туда.
- **Follow On: клик сразу после стрелки побеждает.** Раньше отложенный (~0,1 с) переход от стрелки мог сработать после клика или Backspace и увести Excel обратно. Теперь любой явный переход отменяет отложенный.
- **Excel занят — выделение не теряется.** Если Excel не ответил, где выделение, надстройка спрашивает ещё раз и в крайнем случае берёт ячейку, куда сама перешла. Раньше в этот момент пропадала кнопка «← Back».
- Несколько событий подряд (активация листа + выделение) теперь читаются одним запросом — меньше лишней работы при переходах.
- **Версия видна в ⚙ → Diagnostics** — первая строка, например `Formula Navigator V15.2`.
- Если исследуемую всё-таки нужно сменить на ячейку, куда ты перешёл, — кнопка «⌖ Explore …» в строке над вкладками.
- **Проверки:** 302 автотеста + 136 проверок в браузере. Оба бага сначала воспроизведены на V15.1, после исправления те же сценарии проходят.

## Новое в V15.1

- **Пустые ячейки больше не пропадают из прецедентов.** Раньше в Trace и плавающем окне у `=(Inputs!I200/Inputs!I$11)` была видна только I11, если I200 пустая. Теперь прямая ссылка на одну ячейку видна всегда, пустая помечена серым `(empty)`; в Explore тоже. Это касается и имени, указывающего на одну ячейку, и каждого листа в `Jan:Mar!B5`. Диапазоны (`SUM(I1:I1000)`) по-прежнему показывают только заполненные ячейки.
- **Числа в панели всегда свежие.** Раньше после правки ячейки формулы ниже по цепочке показывали старые значения (Excel не сообщает о пересчитанных ячейках), и даже Rescan их не обновлял. Теперь после любой правки и любого пересчёта (F9, обновление FactSet/Bloomberg, NOW) панель перечитывает всё, что видно: формулу в Explore, раскрытые ▸ ячейки, вкладку Trace. После правки — через ~0,25 с; при пересчётах — не чаще раза в секунду. Rescan тоже обновляет числа.
- **Открытое плавающее окно само обновляет числа** при правках и пересчёте, не сбрасывая раскрытые строки и позицию. Новые связи (если формулу переписали) появятся при повторном Ctrl+Shift+C/D.
- **Подписки на изменения исправлены:**
  - Rescan больше не добавляет повторные подписки (раньше после каждого Rescan одна правка обрабатывалась несколько раз);
  - лист, добавленный после открытия книги, отслеживается сразу (раньше — только после Rescan).
- **Rescan нужен только если:**
  - менял имена в Name Manager или таблицы (новая, расширенная);
  - переименовал лист;
  - добавил/удалил лист, а в модели есть 3-D ссылки — кнопка Rescan сама станет оранжевой.
  Всё остальное (формулы, значения, вставки, новые и удалённые листы) обновляется само.
- **Проверки:** 295 автотестов + прогон в браузере (Chromium) с имитацией Excel — 128 проверок. Настоящий код подписок на события Excel тоже прогоняется на этой имитации.

## Новое в V15

- **Защита от сбоев.** Если вкладка (Explore, Trace, Map, Find) или плавающее окно наткнётся на ошибку, вместо белой панели появится карточка «This view hit an error — **Reload**». Остальные вкладки продолжают работать; переключение на другую вкладку и обратно тоже перезапускает упавшую. Текст ошибки — в **⚙ → Diagnostics** (раздел «UI errors») — его можно скопировать и прислать. В плавающем окне Esc / Enter / Backspace закрывают его даже после сбоя.
- **Follow снова работает в Explore и Trace** (со V2 он фактически работал только в Map).
  - **Follow: on** — идёшь стрелками ↑↓ по дереву, Excel сам переходит на ячейку строки (через ~0,1 с). Исследуемая ячейка при этом не меняется: жёлтая «← Back» или Backspace возвращают к ней.
  - **Follow: off** — просто листаешь; переход только по Enter или клику.
  - По умолчанию включён; выбор запоминается на этом компьютере (сбросится, только если очистить кэш Wef).
  - Клик мышью — ровно один переход.
- **Подсветка формулы.**
  - **Боковая панель:** формула теперь на отдельной строке во всю ширину; часть, на которой стоишь в Explore, подсвечена жёлтым (длинная формула сама прокручивается к ней). Внутри раскрытой ячейки подсвечена ссылка, которую ты раскрыл.
  - **Плавающее окно, низ — две строки:** формула, которая связывает выбранную ячейку с родителем, со ссылкой на неё (Precedents: `in E2: =IF(B2>1000,[B3],B4)`), и собственная формула или значение выбранной ячейки (`B3: 12.5%`). В Dependents — формула зависимой ячейки, где подсвечена ссылка на исходную.
- **Значения и источник в Explore.**
  - Все значения — в одной колонке, выровнены по правому краю.
  - Рядом — колонка связей: `→ D4` у INDEX / VLOOKUP / XLOOKUP / OFFSET (куда попал поиск; у имени — на какую ячейку оно указывает); `← B3` у IF / IFS / CHOOSE / SWITCH / IFERROR / IFNA — из какой ячейки пришло значение (сквозь вложенные IF и поиски); `← then` / `← else`, если сработавшая ветка — выражение (клик ставит курсор на неё).
  - У обычных ссылок значка «→» больше нет — он только повторял адрес.
  - Длинные адреса обрезаются «…», полный — при наведении.
- **Values: as shown / exact** — кнопка рядом с Follow (в Explore и Trace), действует и на плавающее окно.
  - **as shown** — как в Excel: `1,250`.
  - **exact** — скрытые форматом цифры серым: `1,249`**`.6372`**, `12.5`**`372`**`%`, `(1,234)` → `-1,234`**`.48`**. Проценты остаются процентами; даты и текст не меняются; формат «в тысячах» (`#,##0,`) остаётся в тех же единицах.
  - Подсказка при наведении всегда показывает оба значения: `shown: 1,250 · exact: 1,249.6372`.
  - Точное значение читается из Excel в том же запросе, что и видимый текст (не из старого скана).
  - В окне при exact в заголовке значок `exact`; окно перерисовывается сразу, не теряя позиции. Выбор запоминается на компьютере.
- **Подписи аргументов — в той же строке:** `then: B3`, `criteria range: C2:C7`. Функций с подписями — 96 вместо 22 (добавлены SUMPRODUCT, MIN/MAX, MINIFS/MAXIFS, EOMONTH, EDATE, DATE, TEXT, LET, FILTER, SORT, UNIQUE, AND/OR, LEFT/MID, XMATCH, YEARFRAC, ROUNDUP и др.); SUMIFS, COUNTIFS, LET, SWITCH подписываются при любом числе аргументов. Условие IF больше не затемняется как «пропущенная ветка» — затемняется только несработавший результат.
- **Подсказки в окне — две аккуратные строки**, переносятся только между фразами:
  `↑↓ move · →/← open/close · Enter/Esc close · Ctrl+Backspace back`
  `Drag to a corner — it stays · Ctrl+Shift+C/D retarget`
- **Обход совпадений SUMIFS.** Строка `3 of 6 records matched  ◂ 1 / 3 ▸  D2`: ↓ из дерева попадает на неё; → / ← — следующее / предыдущее совпадение, Excel переходит к каждому; ◂ ▸ работают мышкой; до 2 000 совпадений; Backspace — назад к исследуемой ячейке. Ссылки «first matches» остались.
  - Для SUMIFS / SUMIF / AVERAGEIF(S) переход и «first matches» теперь ведут на **суммируемое значение** (колонка sum range), а не на ячейку критерия, как было раньше. У COUNTIFS суммы нет — ведут на ячейку критерия.
- **Проверки:** 282 автотеста + новый прогон в настоящем браузере (Chromium) с имитацией Excel — 103 проверки панели и окна (клавиши, Follow, подсветка, exact, обход SUMIFS, защита от сбоев).
- Без изменений: ничего не пишет в книгу само; горячие клавиши те же (Ctrl+Shift+E/C/D); manifest тот же.

## Установка на новый компьютер (без админа)

1. Закрыть Excel.
2. Из папки `installer` запустить **Install-FormulaNavigator.cmd** (рядом должен лежать `manifest.xml`). Если Windows скажет «Windows защитила ваш компьютер» → «Подробнее» → «Выполнить в любом случае».
3. Открыть Excel → Home → Formula Navigator (или Home → Add-ins → My Add-ins → Developer Add-ins).

Не держи одновременно старый способ через общую папку (Trusted Add-in Catalogs): надстройка может появиться дважды. Удалить старый — File → Options → Trust Center → Trust Center Settings → Trusted Add-in Catalogs → выделить строку → Remove.

## V14 (предыдущая версия)

- **Надстройка больше никогда сама не меняет оформление книги.** Убрана «золотая» подсветка ячейки при переходе и весь модуль покраски. В книгу она пишет только по твоей явной команде: Apply в редакторе формулы, Delete/Restore имени, Unhide all sheets, Export to sheet. Заодно переходы стали быстрее.
- **Безопасное удаление неиспользуемых имён.**
  - Имя, которое используется внутри другого имени или вызывается как LAMBDA (`=МояФункция(A1)`), больше не считается неиспользуемым.
  - Delete спрашивает подтверждение прямо в строке.
  - Перед удалением определение сохраняется; вверху списка появляется «Recently deleted names → Restore».
  - Имена в графиках, проверке данных, условном форматировании и VBA надстройка не видит — об этом прямо пишет подтверждение.
- **Статусы проверки больше не слетают.** ID находки = тип + ячейка, без текста вроде «33/44 cells». Уже проставленные статусы переносятся автоматически.
- **Экспорт аудита = тот же список, что в панели.** Схлопнутые ряды остаются одной строкой, у каждой строки правильный статус и понятное название категории.
- **Гораздо меньше шума в аудите:**
  - не флажатся аргументы функций (`ROUND(x,2)`, `VLOOKUP(…,3,0)`, `INDEX(…,2,3)`, `EOMONTH(x,3)` и др.) и единицы (`×12`, `/1000`, `/365`, `×100`);
  - не флажатся защищённые формулы (`IFERROR`, `IF(A2=0…)`, `IF(A2=""…)`, `ISBLANK`);
  - слэш в тексте (`"FY24/FY25"`) не считается делением; проверяются все деления формулы;
  - плагины распознаются как в макросах v18, включая `_xll.BDP(…)`;
  - `5%` показывается как 5%.
- **Новые ошибки:** `#SPILL!` и `#CALC!`.
- **Один переход на клик** в списке Map.
- **Diagnostics и Validate vs Excel** теперь показывают результат прямо в панели (раньше `alert` в Office не появлялся).
- **Убрана устаревшая легенда цветов** в Map.
- **Клавиатура покрыта автотестами** (161 тест всего), уязвимостей в зависимостях 0.
- **Установка без пароля администратора** — папка `installer`, файл `Install-FormulaNavigator.cmd`.

# История версий (V2–V13)

## V2 — установка через GitHub Pages (исходная инструкция)

Версия V2 = ваша рабочая V1 + 5 исправлений + хостинг на GitHub вместо localhost.
Больше **ничего не запускается на вашем компьютере**: ни serve.js, ни BAT-файлов, ни сертификатов. Excel загружает надстройку с веб-страницы GitHub, как обычную надстройку из магазина.

## Шаг 2. Подключить надстройку в Excel (у себя; коллеги делают то же самое)

Способ называется «общая папка надстроек» (Shared Folder / сетевой каталог). Нужен только файл `manifest.xml`.

### 2.1. Сделать папку «общей»

1. Создайте папку, например `C:\ExcelAddins`, и положите в неё `manifest.xml`.
2. Правый клик по папке → **Свойства** → вкладка **Доступ** → кнопка **Общий доступ…**

## Новое в V5 (трассировка выделенного блока)

Раньше вкладка Trace всегда шла от одной ячейки. Теперь: выделите блок (например, строку Revenue по годам `B5:F5` или столбец допущений) — и Trace построит прецеденты/зависимые **сразу для всех ячеек блока** под общим заголовком «Selection · N cells». Каждая выбранная ячейка — отдельная ветка дерева; раскрываются они как обычно (стрелки/мышь). Это удобно, чтобы одним движением увидеть, откуда питается весь блок.

Как выделять: обычным образом — протянуть мышью или Shift+стрелки (непрерывный блок), либо Ctrl+клик по нескольким ячейкам вразброс. Пустые ячейки в выделении пропускаются. Когда выделена одна ячейка — поведение прежнее. Очень большие выделения ограничены (трассируются первые ~40 ячеек блока, чтобы Excel не подвисал; в заголовке будет «40+ cells»).

Плавающие окна Ctrl+Shift+C/D остаются одноячейковыми, как и были, — многоячейковая трассировка живёт только в панели Trace.

## Совместимость с вашими макросами (горячие клавиши)

Ваши макросы используют сочетания: **Ctrl+Shift+Q, T, R, A, Z, J, M**. Formula Navigator использует только **Ctrl+Shift+C, D, E**. Пересечений нет — их можно спокойно комбинировать.

Важные замечания:
- **Ctrl+Shift+X** надстройка Formula Navigator не занимает (я проверил исходники и сборку — там только C, D, E). И в самом Excel у Ctrl+Shift+X нет стандартной команды. Если он у вас «не срабатывает» — причина не в этой надстройке, а скорее в другом плагине (Bloomberg/FactSet/CapIQ часто забирают Ctrl+Shift+буква) или в оставшемся назначении `Application.OnKey` от прошлой сессии (они живут до перезапуска Excel или до явной отмены).
- Правило на будущее: не назначайте новым надстройкам сочетания из вашего набора (Q/T/R/A/Z/J/M). Если одно и то же сочетание заняли и надстройка (через shortcuts.json), и макрос (через OnKey) — поведение становится непредсказуемым.
- Если какой-то ваш макрос-шорткат внезапно перестал слушаться, проверьте, не висит ли старое назначение: можно временно добавить в макрос строку сброса (например, `Application.OnKey "^+x"` без второго аргумента возвращает X стандартное поведение Excel) или просто перезапустить Excel — `Workbook_Open` переназначит ваши клавиши заново.

## Про ошибку VBA «Code execution has been interrupted»

Это сообщение **твоих макросов (VBA)**, а не надстройки — они в разных мирах, и правки надстройки её не лечат. Самая частая причина: случайное нажатие **Esc, пока работает макрос** (формат/покраска) — в VBA это прерывает выполнение. Лечится одной строкой: в начало тяжёлых макросов (`IB_ColorCode_Selection`, `FormatChartCore`) добавь `Application.EnableCancelKey = xlDisabled`. Если окно выскакивает не при макросах — поймай через кнопку Debug, на какой строке останавливается, и тогда станет ясно.

## Новое в V12 (4 новые проверки аудита)

Аудит (вкладка Map) теперь ловит ещё четыре типа проблем. Все надёжные, с минимумом ложных срабатываний:

- **Пустая ссылка** — формула ссылается на пустую ячейку (забыли заполнить вход или ссылка уехала). Только одиночные ссылки (пустая ячейка внутри диапазона — это норма, не флажок).
- **Формула возвращает ошибку** — ячейка прямо сейчас показывает #REF!, #DIV/0!, #VALUE!, #N/A и т.п.
- **Число хранится как текст** — числовой вход в текстовом формате (из-за этого суммы «не считаются»).
- **Риск деления на ноль** — формула вида `=A/B`, где B пустой или ноль (риск #ДЕЛ/0). Срабатывает только на простом делителе на том же листе — без ложных срабатываний на межлистовых и функциях.

Формулы плагинов (FactSet `=FDS(`, CapIQ `=CIQ(`, Bloomberg `=BDP(` и т.п.) из этих проверок **исключены** — их значения бывают пустыми/с ошибкой не из-за багов модели, а из-за подгрузки данных.

## Новое в V13 (тоньше настроенный аудит)

Две проверки из V12 сделаны менее шумными, по best practices «высокий сигнал важнее полноты»:

- **Ошибки-значения: #N/A больше не флажится.** В живых моделях #N/A — это часто нормальный результат поиска (ВПР/ПОИСКПОЗ «не нашёл»), а не баг. Теперь флажатся только настоящие поломки: **#REF!, #DIV/0!, #VALUE!, #NAME?, #NUM!**. (#NULL! тоже не флажится — редкая и неоднозначная.)
- **«Число как текст» теперь учитывает контекст.** Флажится только если рядом (сверху/снизу/слева/справа) есть настоящее число — тогда текст-число почти наверняка ошибка, ломающая суммы. Одиночная метка вроде «2024» среди подписей больше не помечается.

### Как обновить до V13 на GitHub

В V13 изменился **один** файл. В репозитории: **Add file → Upload files** → перетащить из новой папки `dist` файл **taskpane.js** → **Commit changes**. Перезапустить Excel.

## Как обновлять надстройку в будущем

1. Внесли правки в код → в папке `formula-explorer` выполнить `npm install` (один раз) и `npm run build`.
2. В репозитории GitHub: **Add file → Upload files** → перетащить новые файлы из `dist` → **Commit changes** (одноимённые файлы заменятся).
3. Перезапустить Excel. Если изменения не подхватились — очистить кэш Wef (см. Шаг 3, п. 3).



## Новое в V4 (две функции)

**Журнал аудита со статусами и выгрузкой.** На вкладке Map у каждой находки (и у проблем листа, и у проверок всей книги) слева появилась кнопка-статус: клик переключает «открыто → проверено → вопрос → ошибка». Статусы сохраняются внутри книги и не пропадают при закрытии. Кнопка **Export to sheet** выгружает все находки вместе со статусами на отдельный лист «Formula Navigator Audit» — готовый список «что я проверил перед публикацией». Этот лист не влияет на расчёты и игнорируется самой надстройкой.

**Проверка версии Excel.** Если у вашей (или коллеги) сборки Excel чего-то не хватает — вычисленных значений, подсветки в сетке, плавающих окон или горячих клавиш — вверху панели появится небольшое сообщение, которое прямо называет, что именно недоступно и почему. Его можно закрыть крестиком. Это страховка при раздаче по офису: сразу видно, у кого что не заведётся.

### Как обновить до V4 на GitHub

В V4 изменился только один файл сборки. В репозитории: **Add file → Upload files** → перетащить из новой папки `dist` файл **taskpane.js** → **Commit changes**. Остальные файлы (dialog.js, shortcuts.json, manifest.xml, html) не менялись — трогать не нужно. Затем полный перезапуск Excel (при необходимости очистить кэш Wef, как раньше).

## Если что-то не работает

* **Надстройка не грузится / пустая панель** — проверьте, что открывается https://alimzhansagymbekov.github.io/formula-navigator/taskpane.html и что репозиторий Public.
* **Нет вкладки «ОБЩАЯ ПАПКА»** — каталог не добавлен или нет галочки «Показывать в меню» (Шаг 2.2), либо Excel не перезапущен.
* **Горячие клавиши молчат** — они включаются через несколько секунд после открытия книги; нужен Excel из Microsoft 365 (у вас он есть).
